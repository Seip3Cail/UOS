### 一、命令格式

```bash
# 命令格式
aria2c -x16 -s16 -c
# 多线程下载
aria2c -x16 -s16 -c "直链"
```

### 二、目录参数

| 参数 | 含义 | 说明 |
| --- | --- | --- |
| `-x16` | 对**同一个服务器**最多开 16 条连接 | aria2 的上限就是 16，默认 1 |
| `-s16` | 文件切成 16 段并行拉 | 配合 -x 用 |
| `-c` | 断点续传 | 中断了接着下 |

**x16跟 CPU 线程数无关**——下载是网络活，CPU 基本闲着（htop 可验证）。

- 不会卡 CPU，影响的是**带宽分配**
- 专心下大文件 → `-x16 -s16`，跑满
- 边下边上网 → `-x4 -s4` 够用
- 服务器本身拒绝多连接（如 GitHub 只给 2\~3 条）→ 开多少都白搭，换加速前缀

### 三、wget 和 aria2c 关系

两个**互相独立**的下载器，不是分工合作：

- `wget`：单线程，老牌，简单场景够用
- `aria2c`：多线程，大文件快
- 装Brave.sh 的逻辑：有 aria2 就用 aria2c，没有就退回 wget
  ```bash
  # 来源于程序aria2界面.sh
  #!/usr/bin/env bash
  # ============================================================================
  #  aria2界面.sh —— 给 aria2c 配一个图形界面（网页版 AriaNg，纯本地、不装东西）
  #  WorkBuddy 2026-10-17
  #
  #  背景：aria2c 本身没有窗口，它是个命令行程序。但它带一个"遥控接口"(RPC)，
  #        再配一个网页前端（AriaNg，就一个 index.html，已放在同目录 aria2界面/），
  #        浏览器打开后就有进度条、暂停、续传、看速度——就是图形界面了。
  #
  #  用法：
  #     bash aria2界面.sh        # 起后台服务 + 用浏览器打开界面
  #     bash aria2界面.sh 停     # 关掉后台那个 aria2
  #
  #  注意：服务只听本机 127.0.0.1，别人连不上。
  # ============================================================================
  set -uo pipefail

  PORT=6800
  DIR="$(cd "$(dirname "$0")" && pwd)"
  UI="$DIR/aria2界面/index.html"
  DL="${HOME}/Downloads"
  [ -d "$DL" ] || DL="$HOME"

  say()  { printf '%s\n' "$*"; }
  ok()   { printf '\033[32m%s\033[0m\n' "$*"; }
  warn() { printf '\033[33m%s\033[0m\n' "$*"; }
  die()  { printf '\033[31m%s\033[0m\n' "$*"; exit 1; }

  port_open() { (exec 3<>/dev/tcp/127.0.0.1/$1) 2>/dev/null && exec 3>&- && return 0 || return 1; }

  # ---------------- 停 ----------------
  if [ "${1:-}" = "停" ] || [ "${1:-}" = "stop" ]; then
      if pkill -f "aria2c --enable-rpc" 2>/dev/null; then
          ok "  后台的 aria2 已经关了。"
      else
          warn "  没找到在跑的 aria2，可能本来就没开。"
      fi
      exit 0
  fi

  # ---------------- 起 ----------------
  command -v aria2c >/dev/null || die "找不到 aria2c。"
  [ -f "$UI" ] || die "找不到界面文件：$UI"

  if port_open "$PORT"; then
      say "  服务已经在跑了（端口 $PORT），直接开界面。"
  else
      say "  起后台服务……"
      aria2c \
          --enable-rpc \
          --rpc-listen-all=false \
          --rpc-allow-origin-all=true \
          --rpc-listen-port="$PORT" \
          --continue=true \
          --max-connection-per-server=8 \
          --split=8 \
          --min-split-size=1M \
          --file-allocation=none \
          --auto-file-renaming=false \
          --dir="$DL" \
          --daemon=true || die "  起不来。端口 $PORT 被别的程序占了吧？"
      sleep 1
      port_open "$PORT" || die "  服务没起来。"
      ok "  服务起来了（只听本机 127.0.0.1:$PORT）。"
  fi

  say ""
  say "  默认下载目录：$DL"
  say "  界面文件：$UI"
  say ""

  if command -v xdg-open >/dev/null; then
      xdg-open "file://$UI" >/dev/null 2>&1 &
      ok "  已用浏览器打开界面。"
  else
      warn "  没有 xdg-open，自己用浏览器打开这个文件：$UI"
  fi

  say ""
  say "  界面上怎么用："
  say "    · 左上角【新建】→ 粘贴网址 → 开始。看进度、暂停、续传都在那儿。"
  say "    · 想改下载目录：左边【设置】→ Aria2 RPC / 基本设置里改。"
  say "    · 用完了想关后台：bash $0 停"
  say ""
  say "  如果界面一直显示「未连接」："
  say "    多半是浏览器不让 file:// 页面连本地服务。改用这个（另开一个终端跑，别关）："
  say "      python3 -m http.server 8686 --bind 127.0.0.1 --directory \"$DIR/aria2界面\""
  say "    然后浏览器开：http://127.0.0.1:8686/index.html"
  say ""
  ```

### 四、怎么判断一个网址是不是"直链"？

经验法则：**网址末尾能看到完整文件名+扩展名**（如 `xxx.deb`、`xxx.zip`）基本是直链。

**不是铁律**：有些直链不带扩展名，真实文件名在**响应头**里给：

```bash
curl -sI "网址" | grep -iE "content-disposition|content-type|content-length"
```

- `Content-Disposition: attachment; filename="xxx.zip"` ← 服务器明说的文件名
- `Content-Type: application/zip` ← 类型
- `-I` = 只要响应头，不要文件内容

### 五、curl 的 `-o` 和 `-O` 有什么区别？

- `-o 文件名` = **自己指定**输出文件名
- `-O` = 用**网址里的原名**保存
- 大小写敏感！`-i`（头+正文）和 `-I`（只要头）同理

规律：**短横线后那截就是命令的"开关名"**，各家命令开关不同，靠 `--help` 查，不用背。

### 六、r.jina.ai 是什么？怎么用？

**把任意网页转成 Markdown 文本的免费服务**。用法就一招——前缀拼接：

```bash
curl "https://r.jina.ai/https://目标网址" -o 文件名.md
```

- `-o` 后面是输出文件名，落在**当前目录**（先 `pwd` 确认）
- 文件名带日期带主题：`文件名.md` 比 `文件名-10-19.md` 好找，文件名可以用中文
- 不加 `-o` 直接刷屏；加 `| head -50 | tail 30` 先看头50行或尾部30行(倒数)

### 七、抓多了会被封吗？

两档，不一样：

|   | 表现 | 持续 |
| --- | --- | --- |
| **频率限制** | 返回 `HTTP 429 Too Many Requests` | 几秒到几分钟，缓过来就好 |
| **封禁** | IP 拉黑 | 几小时到几天 |

`r.jina.ai` 属于前者：按 IP 计数，超了先拒一会儿。**正解是慢点、失败了隔一会儿再试**，连着猛敲恢复更慢。看状态码：

```bash
curl -i "网址" | head -20     # 看到 429 就是被限流
```

### 八、curl的使用

```bash
# 只看响应头（找文件名/类型/大小）

curl -sI "网址" | grep -iE "content-disposition|content-type|content-length"

# 网页转 md 存文件

curl "https://r.jina.ai/https://目标网址" -o 名字.md

# 看状态码（排错）

curl -i "网址" | head -20
```
