aria2 图形下载器 · 使用说明
================================

【一、怎么用】
双击「启动下载器.sh」→ 浏览器自动弹出页面 → 点左上角「+」粘链接 → 确定，开始下。
页面就是遥控器，下载在后台跑，关掉页面也不影响。

【二、页面里能干什么】
· HTTP / HTTPS / FTP / SFTP 链接，.torrent 种子文件，磁力链接（magnet:?xt=...）
· 每个文件 16 线程，同时下 5 个，多的排队
· 暂停、继续、限速、看实时速度、看每个任务的分段进度
· 改保存位置：左侧「设置 → Aria2 设置 → 基本 → 下载目录」
  默认是 家目录/下载（第一次启动会自动建好）

【三、怎么关】
双击「停止下载器.sh」。
没下完的任务会记在同目录 aria2.session 里，下次启动自动接着下（断点续传靠它）。

【四、想放进应用菜单】
把 aria2下载器.desktop 复制到 ~/.local/share/applications/
（也可以在文件管理器里右键这个 .desktop → 属性 → 允许作为程序执行）

【五、出问题看这里】
1. 页面右上角写「未连接」或红点：
   点右上角齿轮 → AriaNg 设置 → RPC → 地址填 http://127.0.0.1:6800/jsonrpc
   密钥留空。
2. 速度一直是 0，日志里是 TLS / 连接失败：
   说明这台机器上 aria2 连不到那个地址。挂了代理软件的话，aria2 不会自动走代理，
   要在「设置 → Aria2 设置 → 基本 → 额外参数」里加一行：
   --all-proxy=http://127.0.0.1:你的代理端口
3. 点了没反应：看同目录下的 aria2.log 最后几行。

【六、这个目录里都是什么】
index.html          AriaNg 网页界面（单文件，2.3 MB，已改好默认连本机 6800 端口）
启动下载器.sh        起 aria2 + 打开页面
停止下载器.sh        存盘退出
aria2下载器.desktop  给应用菜单用的启动项

注：index.html 来自 AriaNg 1.3.15 官方发布包，只改了一个默认值
（rpcHost 从空改为 127.0.0.1），否则用本地文件打开时它不知道连哪。
