## 二、下载软件选择

### 1.wget vs curl

| **比较** | **wget(World Wide Web get)** | **curl(Client for URLs)** |
| --- | --- | --- |
| 什么样的工具 | 是一个从网络上自动下载文件的自由工具 | 是一个功能强大且广泛使用的工具。有瑞士军刀之称它可以与各种协议进行通信，如HTTP、HTTPS、FTP等，并支持各种操作，如下载文件、发送请求、测试API等。 |
| 协议支持 | 支持 HTTP、HTTPS 和 FTP 协议。 | 支持HTTP、HTTPS、FTP、SFTP、SMTP等26种协议 |
| 用途 | 1.非常适合脚本和自动化任务。2.它是一个非交互式工具，可以在后台运行。3.专注于**可靠的网络文件**下载递归抓取和断点续传。 | 1.一个多功能URL客户端工具2.支持多种协议的数据传输的瑞士军刀 |
| 文件保存 | wget直接以原始文件名保存到**当前目录** | 需要显式指定-o参数保存文件 |
| 支持场景 | \*\*简单文件下载/网站镜像：\*\*wget -c 断点续传, wget -r 递归下载,wget -b 后台运行 | \*\*API测试/复杂HTTP请求：\*\*curl -H 自定义请求头,curl -d POST数据,curl -v 详细调试 |
|   |   |   |
|   |   |   |
| 功能指标 | curl实现方案 | wget实现方案 |
| 输出控制 | -o/-0 指定输出文件 | 自动以远程文件名保存 |
| 进度显示 | -# 简单进度条 | 内置彩色进度条与速率统计 |
| 断点续传 | -C -自动续传 | -c 继续未完成下载 |
| 限速下载 | --limit-rate=200K | --limit-rate=200k |
| 后台下载 | 需配合nohup或tmux | 原生支持 -b 参数后台下载 |

wget 通过--span-hosts和--trust-server-names参数可实现类似**多线程下载**

### 2.协议支持

| 协议 |   | curl 支持 | wget 支持 |
| --- | --- | --- | --- |
| HTTP/HTTPS |   | ✅ | ✅ |
| FTP/FTPS |   | ✅ | ✅ |
| SFTP |   | ✅ | ❌ |
| SCP |   | ❌ | ✅ |
| SMTP |   | ✅ | ❌ |
| HTTP/2 |   | ✅ | ❌ |
| HTTP/3 |   | ✅ | ❌ |

\*\*注：\*\*wget 通过插件可扩展部分协议支持，但 curl 的协议集成度更高

\*\*错误处理：\*\*curl 的-f/ --fail参数能在 HTTP 错误时返回非 0 状态码，而 wget 默认就会在失败时退出

### 3.命令参数对照

不用背参数\*\*——每个命令的"开关名"各家不同，查 `--help` 是正路。

| 命令 | 参数 | 含义 |
| --- | --- | --- |
| `curl -o 名字` | 输出到文件 | 自己指定名字 |
| `curl -I` | 只要响应头 | 查文件名/类型/大小 |
| `curl -i` | 头 + 正文 | 排错看状态码 |
| `aria2c -x16 -s16 -c` | 连接数/分段/续传 | 多线程下载 |
| `wget -c` | 续传 | 断点接着下 |
| `mount -o noauto,users` | 挂载选项 | 控制挂载行为 |
| `grep -i` | 忽略大小写 | 搜索 |

**注意大小写**——文件名如此，命令参数也如此：

- `curl -o`（输出到文件）和 `-O`（用原名保存）是**两个不同参数**
- `curl -i`（头+正文）和 `-I`（只要头）同理
- `LS` 不是命令，`Readme` 和 `readme` 是两个文件
- curl -o 文件名              # 短参数：一个减号 + 单字母
- curl --output 文件名        # 长参数：两个减号 + 单词（同一个意思）
- 短参数**能合并**：`ls -la` = `ls -l -a`
- 长参数**不能合并**，但意思更易读

### 5.HTTP 状态码 429 是什么？

**被限流**（Too Many Requests）：短时间内请求太密，服务方拒绝，缓一会儿自动恢复。
跟"封 IP"不同——封禁是长期的，429 是临时的。

见到 429 的正确反应：**停手，隔几分钟再试**，连着重试恢复更慢。

### 6.命令的基本结构

```
命令     -参数        目标
aria2c   -x16 -s16    "网址"
mount    -o ro        /dev/sdb1  /mnt/xx
```

三段式：**干什么 → 怎么干 → 对谁干**。所有命令都是这个骨架的变体。
