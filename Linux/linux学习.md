## 〇、Linux 到底是什么（只记一句话）

**Linux 是一个「内核」** —— 就是管 CPU、内存、硬盘、网卡的那一层底层程序。它自己没界面、没软件，不能直接拿来用。

你装的 **deepin = Linux 内核 + 一堆软件 + DDE 桌面（就是那套图形界面）+ 包管理器（负责装软件、卸软件的管家）**。像这样拼好的成品，叫做**发行版**。

|   | Windows | Linux |
| --- | --- | --- |
| 底层内核 | NT | **Linux** |
| 拼好的成品叫什么 | Windows 10 / 11 | deepin、Ubuntu…（叫**发行版**） |
| 软件从哪来 | 商店、各官网下载 exe | **发行版的「软件仓库」**（`apt` 就是进这个仓库的门） |
| 界面 | 资源管理器 + 开始菜单 | 文件管理器 + 启动器 |

**为什么先讲这一句**：以后你遇到的每一个"deepin 怎么跟 Windows 不一样"的问题，答案都在**发行版**这一层（软件从哪来、桌面长什么样），不在内核。所以"Linux 的历史"不用管，那是教材的写法。

## 一、新手上路：进系统后你会先问的 9 件事

> 这一章只讲**你要做什么**、**最少要敲哪几条**。命令的完整说明（做什么、达到什么目的、相当于 Windows 什么功能）统一放在 [§三](#s3)，这里不重复。

### 1.1 这系统里都有什么？跟 Windows 的哪个对应？

先认路：按一下键盘左下角那个**带窗户图标的键**（就是 Windows 键，下面叫它「Win 键」）→ 弹出**启动器**，装了的程序全在这儿，能直接打字搜。

下面这张表，左边是你用了半辈子的 Windows，右边是 deepin 里对应的东西。**认全这张表，"这系统里有什么"就解决大半了。**

| Windows 里叫什么 | deepin 里叫什么 | 怎么打开 |
| --- | --- | --- |
| 开始菜单 | **启动器** | 按 Win 键 |
| 我的电脑 / 资源管理器 | **文件管理器** | 点任务栏上的文件夹图标 |
| 控制面板 | **控制中心** | 任务栏右侧那排小图标里找 |
| 任务管理器 | **系统监视器** | Win 键 → 搜"系统监视器" |
| 微软商店 | **应用商店 / 星火商店** | 任务栏 / 启动器 |
| Windows 更新 | 控制中心 → 系统更新 |   |
| 记事本 | 文本编辑器 |   |
| 事件查看器 | 日志收集工具 |   |
| 命令提示符（cmd） | **终端** | 按 `Ctrl + Alt + T` |
| 设备管理器 | 控制中心 → 设备 |   |
| 磁盘管理 | 分区编辑器（GParted，要另装） |   |

**不用记软件名字，按功能搜就行**：想截图、想解压、想听歌、想下载 —— 去**星火商店**搜中文功能词，或者在终端里 `apt search 关键词`（说明见 [§3.9](#s3-9)）。Windows 上用的软件，Linux 几乎都有对应的，只是名字不一样 —— 名字对照见 [§四 工具字典](#s4)。

### 1.2 我的文件在哪？盘在哪？

新手最容易懵的一步：**这里没有 C 盘、D 盘。**

**你的东西全都放在一个地方**：`/home/wsqw`，简写成一个波浪号 `~`。它就相当于 Windows 里的 `C:\Users\wsqw`（"我的文档"那一带）。你放桌面上的、下载下来的，也都在这个"家目录"里。

**先记住 3 条命令，就不会迷路：**

```bash
pwd        # 我现在站在哪个目录里
ls         # 这个目录里有什么
cd ~       # 回家（回我自己的地盘）
```

（这三条各是什么意思、相当于 Windows 的什么操作 → 见 [§3.1](#s3-1)）

**别的盘呢？** Linux 里没有"盘符"这回事，插上 U 盘也不会自己蹦出一个 `E:`。**所有盘都要先「接」到一个文件夹上，才能看见里面的东西** —— 这个动作叫**挂载**。为什么是这样，见 [§2.1](#s2-1)；怎么挂，见 [§3.7](#s3-7)。

### 1.3 这个命令怎么用？—— 会查说明书，就不用背命令

**这是"能自己用 Linux"最关键的一步。命令不用背，会查就行。**

```bash
ls --help      # 最快的：列出这个命令的所有参数
man ls         # 完整的说明书：上下键翻页，/ 搜关键词，q 退出
```

**说明书里那句"命令格式"怎么读？** `--help` 和 `man` 的开头都会有一行叫 `Usage`（用法）或 `SYNOPSIS`（摘要），里面有一堆符号，规矩是固定的：

| 符号 | 意思 | 例子 |
| --- | --- | --- |
| `[选项]` | 方括号里的，**可以不写** | `ls [-a]` 里的 `-a` 可写可不写 |
| `<文件>` 或者直接写 `文件` | **必须写** | `cp <源> <目标>` |
| `...` | 可以**写好几个** | `cp 源1 源2 ... 目标` |
| `-a ``\| -b` | **二选一**，不是都能写 |   |
| `-r, -R, --recursive` | 同一个意思的三种写法 |   |

看个实例：`man ls` 里写着 `ls [选项]... [文件]...`
→ 意思就是：`ls` 后面**可以什么都不写**（那就列出当前目录），也可以写**好几个选项、好几个文件**。

`man`** 说明书怎么读**：**别从头读到尾**。敲 `/你想查的词`，回车，就跳过去了；按 `n` 看下一个；按 `q` 退出。

> `man` 是分了章节的。常看的三章：**1** = 普通命令、**5** = 配置文件、**8** = 系统管理命令。
> 想直接看某个配置文件的手册，得写明章节，比如 `man 5 fstab`（`fstab` 是啥见 [§3.7](#s3-7)）。

### 1.4 命令敲错了、想再敲一遍、忘了

终端里有一套"按键快捷方式"，学会了能省一半力气。**每条都说明它干什么、相当于 Windows 里怎么操作：**

| 按键 / 写法 | 做什么 | 相当于 Windows |
| --- | --- | --- |
| `↑` | 调出上一条命令，回车就再跑一遍 | 聊天框里按上键，找回上一句 |
| 一直按 `↑` / `↓` | 一条条往前翻 / 往后翻历史命令 | 同上的加强版 |
| `Ctrl + R` | **搜索**历史命令（输入关键词，边打边找） | 浏览器的 `Ctrl + F` |
| `Tab` | **自动补全**命令名或路径（打一半按一下） | 没有，这是 Linux 的独门绝活，很好用 |
| `Ctrl + C` | 扔掉正在敲的这一行；命令正在跑就中断它 | 有点像"取消" |
| `!$` | 重复上一条命令的**最后一个参数** | 无 |
| `Ctrl + A` / `Ctrl + E` | 光标跳到行首 / 行尾 | 按 `Home` / `End` |
| `Ctrl + U` / `Ctrl + K` | 删掉光标前 / 后的整行 | 无 |

**敲错了怎么办**：`Ctrl + C` 直接扔掉这一行，重新敲，别按半天退格。

### 1.5 屏幕刷屏了、输出太长

| 我想… | 怎么做 | 说明 |
| --- | --- | --- |
| 清掉一屏乱七八糟的 | 敲 `clear` 或按 `Ctrl + L` | **注意：这只是把屏幕往上推，内容没删**，往上滚还能看见 |
| 往回看刚滚过去的 | `Shift + PgUp` / `Shift + PgDn`，或滚鼠标滚轮 |   |
| 命令输出太长、哗哗刷屏 | 在命令后面加 ```\| less` | 一屏一屏地看，按 `q` 退出 |
| 只看开头 / 结尾几行 | 加 ```\| head -20` / ```\| tail -20` |   |
| 盯着日志实时滚动 | `tail -f 文件名` | 按 `Ctrl + C` 退出 |
| 命令卡住不动了 | `Ctrl + C` |   |
| 终端花屏 / 乱码 | 敲 `reset`，回车（看不见也照敲） |   |

`clear`、`less`、`head`、`tail` 的完整说明 → 见 [§3.1](#s3-1)。

嫌终端能往回翻的行数太少：终端窗口里右键 → 设置 → 把"回滚行数"调大（默认一般是 1000 行）。

### 1.6 现在机器在忙什么？

**图形上**：Win 键 → 搜"**系统监视器**" —— 就是 deepin 版的任务管理器，能看谁在吃 CPU 和内存，右键就能结束它。

**命令**：

```bash
top                                # 实时看进程排名（按 q 退出；按 M 按内存排、按 P 按 CPU 排）
free -h                            # 看内存用了多少（-h = 用人看的单位，不是一堆字节数）
df -h                              # 看每块盘还剩多少空间
ps aux --sort=-%cpu | head -10     # 揪出吃 CPU 最狠的前 10 个进程
```

发现某个程序卡死了，要强行关掉它：

```bash
pgrep 程序名     # 先查出它的编号（PID）
kill 编号        # 客气地请它退出
kill -9 编号     # 还不退，强杀（它来不及保存东西）—— 相当于任务管理器里的"结束任务"
```

**这些命令的详细说明、分别相当于 Windows 哪个功能 → 见 **[§3.6](#s3-6)**。**

你这台机器是 N 卡，还会用到：

```bash
nvidia-smi     # 看显卡在干什么、占了多少显存
sensors        # 看各部件温度（要先装：sudo apt install lm-sensors）
```

### 1.7 磁盘满了、垃圾怎么清？

**先看清楚是谁占了地方，再动手删。别上来就删。**

```bash
df -h                        # 第一步：看哪块盘满了
du -sh ~/* | sort -h | tail  # 第二步：看家目录里谁最占地方（从小到大排，看最后几行）
ncdu ~                       # 第三步（推荐）：装个图形化的，能像资源管理器那样一层层点进去看
```

能安全清的，按"省得最多"排序：

| 清什么 | 怎么清 | 说明 |
| --- | --- | --- |
| apt 下载的安装包缓存 | `sudo apt clean` | 常能省几百 MB，**完全安全** |
| 没用的旧依赖包 | `sudo apt autoremove` | ⚠ **先看它列出来要删什么，确认了再回车** |
| 系统日志 | `sudo journalctl --vacuum-size=200M` | 把日志压到 200MB 以内 |
| 回收站 | 文件管理器里清空 |   |
| 缩略图缓存 | `rm -rf ~/.cache/thumbnails/*` | 会自动重建，安全 |
| 浏览器缓存 | 浏览器的设置自己手动清理 |   |

**三条红线**（完整版见 [§2.7](#s2-7)）：

1. **别删 **`/var`**、**`/usr`**、**`/etc`**、**`/boot`** 里的东西** —— 那不是垃圾，那是系统本身。
2. `du` 显示"大"的目录，**不等于**垃圾，先看清是什么再决定。
3. **Windows 那块盘（NTFS）上的东西，优先回 Windows 清** —— 那边有磁盘清理和回收站，更安全。

### 1.8 软件怎么装、怎么卸、装不上怎么办

**Windows 习惯**：上官网下个 `.exe`，双击，下一步下一步。
**Linux 习惯**：从**发行版的软件仓库**里装 —— 一句话搞定，它需要的别的软件（叫"依赖"）自动帮你装齐。

```bash
apt search 关键词        # 先在仓库里搜，看有没有
apt show 包名            # 看它是什么、多大、依赖谁
sudo apt install 包名    # 装
sudo apt remove 包名     # 卸（保留配置文件）
sudo apt purge 包名      # 卸 + 连配置一起删干净
```

**图形入口**：应用商店 / 星火商店，搜到了点"安装"。底层还是 apt，只是套了层图形界面。

**商店里没有的：**

- 下载到一个 `.deb` 文件 → `sudo apt install ./文件名.deb`（**开头那个 **`./`** 不能少**）
- 绿色软件（叫 **AppImage**，就是一个文件）→ 右键属性里给它"可执行"权限，或者 `chmod +x 文件名`，然后双击就能跑

**装不上 / 升级出问题的三个常见原因：**

1. `apt list --upgradable`** 列出来的包，不一定该升。** 它只看"仓库里版本号更高"。deepin 上有些自家维护的包（比如输入法）被列出来很正常，**升了反而坏**。拿不准就别升。
2. **依赖冲突**：apt 会告诉你缺什么，照着提示先把那个装上。
3. **软件源的问题**（软件源 = 你的电脑从哪台服务器下载软件，也就是"仓库的地址"）：控制中心 → 系统更新 / 软件源，可以在那儿切换源、刷新源。

**别在 Linux 里找 **`.exe` —— 找不到。真要跑 Windows 程序，那是 Wine 的活儿（见 [§四](#s4)）。

完整命令清单和软件的几种形态 → 见 [§3.9](#s3-9)；为什么是"从仓库装"而不是"从官网下载" → 见 [§2.5](#s2-5)。

### 1.9 出错了，先看哪里

**顺序**：先**读报错那句话** → 再看**日志** → 实在不行，才上网搜。

```bash
journalctl -xe                     # 看最近的系统错误（最常用）
journalctl -u 服务名 -n 50          # 看某个服务最近 50 行日志
journalctl --since "10 min ago"    # 看最近 10 分钟系统里发生了什么
dmesg | tail -30                   # 内核报的消息：插 U 盘没反应、硬盘认不出，看这个
```

**图形上**：Win 键 → 搜"**日志收集工具**"，按时间、按类型翻，比命令直观。

**读报错的三条原则：**

1. **只看最后一两行。** 真正失败的原因通常在那，别被中间几十行吓住。
2. `No such file or directory` = 路径或文件名写错了（大小写、斜杠方向）—— 九成是手滑。
3. `Permission denied` = 权限不够 → 该加 `sudo` 的加；**但先想清楚是不是真需要**（见 [§2.3](#s2-3)）。

这些日志命令的完整说明 → 见 [§3.6](#s3-6)。

## 二、核心基础：为什么会这样

> 这一段回答"**为什么 Linux 跟我们习惯的不一样**"。不用背，但要看明白 —— 以后所有报错，都能在这里找到解释。这一章以讲道理为主，需要敲的命令一律指向 [§三](#s3)。

### 2.1 一棵树，没有 C 盘

**Windows 的思路**：一个分区配一个盘符，`C:\`、`D:\` 各是一棵独立的树；插上 U 盘，自动多出来一个 `E:`。

**Linux 的思路**：**全世界只有一棵树**，树根是 `/`（就叫"根目录"）。硬盘、分区、U 盘**都不会自己出现**，必须「**接**」到树上某个文件夹里，才能看见里面的东西 —— 这个动作叫**挂载**。

```
/                       ← 唯一的树根
├── home/
│   └── wsqw/           ← 你的地盘，相当于 C:\Users\wsqw
├── etc/                ← 系统配置（相当于注册表，但它是能直接改的文本文件）
├── dev/                ← 设备（硬盘、键盘…都在这里，见 §2.2）
├── mnt/                ← 临时挂东西的地方（Windows 那块盘就挂在下面的 winc）
├── media/              ← U 盘、光盘一般自动挂到这里
├── tmp/                ← 临时文件，重启就清空
├── usr/ 、bin/         ← 程序装在哪
├── var/log/            ← 日志
└── boot/               ← 开机引导。⚠ 不懂别动
```

对照着记：

| 概念 | Windows | Linux |
| --- | --- | --- |
| 怎么访问一个分区 | 给它一个盘符，`C:` `D:` | 把它**接到某个文件夹**上，比如 `/mnt/winc` |
| 系统盘 | `C:\` | `/` |
| 你的文件 | `C:\Users\wsqw` | `/home/wsqw`（简写 `~`） |
| 配置放哪 | 注册表（二进制，得用 `regedit` 看） | `/etc` 和 `~/.config` 里的**文本文件**，能直接改、能备份 |
| 设备 | 设备管理器（图形） | `/dev` 里的一堆文件（见 §2.2） |

**这条观念最实际的后果**：你那块 20T 硬盘，不会像 `E:` 一样自己冒出来。你必须告诉系统"把它接到 `/mnt/xx` 下面去"。**这就是要折腾 **`/etc/fstab`** 的全部原因** —— 怎么挂，见 [§3.7](#s3-7)。

### 2.2 一切皆文件

Linux 把**硬盘、分区、键盘、网卡，甚至"把数据丢掉"这个功能**，统统表示成文件。

- `/dev/sda` = 第一块 SATA 硬盘（`sda1` 是它的第一个分区）
- `/dev/null` = 黑洞。写进去的东西全丢弃，读它立刻返回"结束"。相当于 DOS 里的 `nul`

`/dev` 目录里怎么一眼分辨？**看权限位（就是 **`ls -l`** 每行最前面那个字母）：**

| 开头字母 | 类型 | 例子 |
| --- | --- | --- |
| `b` | **块**设备（按"块"读写，上面能放文件系统） | 硬盘、分区、U 盘、光驱 |
| `c` | **字符**设备（按字符流读写） | 键盘、鼠标、`/dev/null` |
| `d` | **目录** | 就是文件夹 |
| `l` | **符号链接** | 就是快捷方式 |
| `-` | **普通文件** | 文档、图片这类 |

**为什么这个观念值钱**：理解了"一切皆文件"，你就理解了两件事 ——
① 命令为什么能直接操作硬件（因为硬件在 Linux 眼里也是文件）；
② 配置为什么能直接改（因为配置也是文件）。

### 2.3 用户、权限与 root

**Windows**：有个"管理员账户"，需要提权时弹个 UAC 窗口让你点确定；权限靠一套叫 ACL 的复杂名单（谁能看、谁能改、能不能继承）来管，都在图形界面上点。

**Linux**：权限是**写在每个文件上的 9 个字母 + 2 个名字**（属主、属组），一目了然。

```
-rwxr-xr-x  1 wsqw wsqw  1024 10月10日 12:00 脚本.sh
│└┬┘└┬┘└┬┘    │    │     │
│ │  │  │     │    │     └─ 大小
│ │  │  │     │    └─────── 属组（属于哪个组）
│ │  │  │     └──────────── 属主（谁拥有它）
│ │  │  └────────────────── 其他人：r-x（能读、能执行，不能写）
│ │  └───────────────────── 同组的人：r-x
│ └──────────────────────── 属主本人：rwx（能读、能写、能执行）
└────────────────────────── 文件类型（- 是普通文件）
```

- `r` = 读（记 4）、`w` = 写（记 2）、`x` = 执行（记 1）。三组加起来就是数字：`rwxr-xr-x` = 755
- **目录上的 **`x`** 意思是"能不能进这个目录"**，不是"能不能运行"

**root 是什么**：系统里权限最高的那个账户（相当于 Windows 里把 SYSTEM 和管理员合成一个）。**默认不能用 root 登录桌面**，需要的时候"借"一下：

```bash
sudo 命令       # 以 root 的身份跑这一条命令（会问你的密码）
```

**三条必须记住的：**

1. `sudo` 只借**这一条命令**，不是"进入了管理员模式"，用完就还。
2. **越是习惯当 root，越容易被自己坑** —— root 删东西不问、也不进回收站。
3. 你的账户本来就能干 99% 的日常事，**不要没事就加 **`sudo`。加之前先问自己：这真的是系统级操作吗？

权限具体怎么改（`chmod`、`chown`）→ 见 [§3.4](#s3-4)。

### 2.4 ext4 和 NTFS 的权限不是一回事（双系统必踩）

先说清楚"**文件系统**"这个词：它就是**硬盘上组织、存放文件的那套格式**。Windows 常用 NTFS（比如 C 盘）和 exFAT（比如 U 盘）；Linux 自己常用 ext4。

- deepin 自己的分区用的是 **ext4**：支持 Linux 那 9 位权限、属主、属组 → `chmod` / `chown` 都生效
- Windows 那块盘用的是 **NTFS**：NTFS 里根本没有 rwx 这套东西（它用的是前面说的 ACL）

**所以：挂载 NTFS 盘时，权限是在挂载那一刻就一次性定死的**（靠 `uid=`、`gid=`、`umask=` 这些挂载参数）。你在 NTFS 上跑 `chmod`，**什么效果都没有** —— 不报错，但也不生效。

|   | ext4（deepin 自己的盘） | NTFS（Windows 的盘） |
| --- | --- | --- |
| 每个文件单独设权限 | ✅ 可以 | ❌ 全盘一套 |
| `chmod` / `chown` | 生效 | **无效**（而且不报错） |
| 加可执行位 `+x` | 生效 | 由挂载参数决定 |
| 删除文件 | 走回收站 | 直接进 `.Trash-1000` |

**顺带两个必知的 NTFS 坑：**

- **快速启动 / 休眠**：Windows 没真正关机（开着"快速启动"）就切到 Linux，NTFS 会处于"脏"状态 → 能读不能写，甚至压根挂不上。**必须在 Windows 里关掉快速启动**。
- **文件系统损坏**：别在 Linux 上"修" NTFS —— **拿回 Windows 用 **`chkdsk`** 修**。Linux 的 `ntfsfix` 只是个小补丁，不该当修复工具用。

### 2.5 软件从哪来

**Windows 习惯**：去官网下个 `.exe`，双击，下一步下一步。

**Linux 习惯**：从**发行版的软件仓库**装。一条命令，它需要的别的软件（依赖）自动帮你解决。

```bash
sudo apt update      # 刷新"仓库清单"（★ 只是刷新清单，不装任何东西）
sudo apt upgrade     # 按新清单，真正执行升级
```

⚠ `update`** 和 **`upgrade`** 是两个动作，最常搞混。** 记忆法：**update 去拿目录，upgrade 才动手干活**。

**软件有 4 种形态，认准了就不会找错：**

| 形态 | 长什么样 | 怎么处理 |
| --- | --- | --- |
| 仓库包 | 没有文件，直接 `apt install 名字` | 最优先，干净、好卸载 |
| `.deb` | 单个文件，像 `.msi` | `sudo apt install ./xxx.deb` |
| AppImage | 单个文件，加上执行权就能跑 | `chmod +x` 后双击，等于**绿色软件** |
| 源码编译 | `.tar.gz` + `./configure && make` | 能避开就避开 |

**deepin 的额外入口**：自带的**星火商店 / 应用商店**，底层还是 apt 那套，只是套了图形界面。

完整命令清单 → 见 [§3.9](#s3-9)。

### 2.6 终端的基本语法

一条命令就三段：

```
命令     -参数        目标
ls       -l           /home/wsqw
```

参数有两套写法：

- **短参数**：一个减号 + 单个字母，如 `-l`、`-a`、`-h`。**能合并写**：`ls -la`
- **长参数**：两个减号 + 单词，如 `--help`、`--all`。**不能合并**

**四条铁律（从 Windows 过来最容易踩的）：**

1. **严格区分大小写。** `Readme` 和 `readme` 是两个不同文件，`LS` 不是命令。这是 Windows 老手最持久的"手感错误"。
2. **路径用正斜杠 **`/`**。** Windows 用的反斜杠 `\`，在 Linux 里是**转义符** —— 所谓转义符，就是"给后面跟着的那个字符换个意思"的记号，跟路径划界完全不搭边。
3. **空格是分隔符，不算文件名的一部分。** 文件名里有空格要加引号：`cd "我的 目录"`；或者敲到一半按 `Tab`，让它自己帮你转义。
4. `~`** = 你的家目录**，就是 `/home/wsqw` 的简写。`~/.bashrc` 就是 `/home/wsqw/.bashrc`。

**路径分两类：**

|   | 写法 | 意思 |
| --- | --- | --- |
| 绝对路径 | `/mnt/winc/WorkBuddyData` | 从树根 `/` 出发，走哪都一样 |
| 相对路径 | `WorkBuddyData`、`../abc` | 相对于"我现在在哪"。`.` = 当前这一层，`..` = 上一层 |

（终端里的按键操作、历史命令复用、清屏 —— 都在 [§一 1.3–1.5](#s1-3)，那是新手最先要会的。）

### 2.7 危险红线：先记这 6 条

**终端里的删除不进回收站。** 这是从 Windows 过来最大的行为改变。图形文件管理器里删除还有回收站可以捞（回收站的文件在 `~/.local/share/Trash`），**终端里 **`rm`** 下去就是真没了**。

| 命令 | 危险在哪 | 规矩 |
| --- | --- | --- |
| `rm -rf 目录` | `-r` 递归删到底、`-f` 什么都不问。**没有撤销** | 删之前先 `ls` 看一眼；拿不准的先 `mv` 到 `/tmp` 放几天 |
| `rm -rf /` 或 `rm -rf ./*` | 能把整个系统清空 | **看到这种命令，先停下来想三秒** |
| `sudo 任意命令` | 借了 root 的权，破坏力 ×10 | 加 `sudo` 前，先问自己是不是真需要 |
| `chown -R` / `chmod -R` | 递归改一整棵树的属主 / 权限 | 只在自己家目录用；加 `-R` 前先 `ls -l` 确认路径 |
| `dd` / `mkfs` | 直接往裸设备上写，**打错一个字母就毁盘** | 不确定就别用 |
| `apt autoremove` | 会删掉"它认为"没人要的包，**可能连带删掉你要的东西** | 先看它列什么，确认了再回车 |

**三个降风险的反射动作：**

1. 敲回车之前，先把自己的命令的**目标**和**参数**再看一遍。
2. 终端里删东西之前，先 `ls` 同一个路径确认。
3. 图形界面能做的事就用图形界面（文管删除有回收站），**危险的活别在终端里干**。

### 2.8 上手三分钟（现在就能跑）

目标：**亲眼看见"一切皆文件"和"只有一个树根"这两件事**。

```bash
ls -l /dev/null        # 看开头那个字母，是不是 c
lsblk                  # 列出所有"块设备"（硬盘、分区、U盘）的真实名字
ls -l /dev/sda         # 把 sda 换成上一步看到的真名，看开头是不是 b
df -h                  # 看每棵"接在树上"的分区，各还剩多少空间
pwd                    # 看你现在站在树的哪个位置
```

**参数逐个解释：**

- `ls` = list，列出内容
- `-l` = long，**长格式**。不加只列文件名；加了会多显示权限位、属主、大小、时间 —— 这是以后用得最多的参数
- `-h` = human，把数字变成人能读的（`4.0K` 而不是 `4096`）
- `lsblk` = list block，是个独立命令，不用加参数。`sda` 是老式接口的名字，NVMe 固态硬盘叫 `nvme0n1`

**顺带一个命令家族**：`ls`、`lsblk`（块设备）、`lscpu`（CPU）、`lsusb`（USB）、`lspci`（PCI 设备）、`lsmem`（内存）—— 全是 `ls*` 一个套路，见到就懂。

> 看到 `/dev/sda` 开头那个 `b`、`/dev/null` 开头那个 `c`，你就理解了"一切皆文件"和"块/字符设备"的区别。这一步比读十页教材管用。

### 3.2 建、改、删

| 命令 | 做什么 | 达到什么目的 | 相当于 Windows |

| `mv 源 目标` | 移动；目标写新名字就是**改名** | 挪位置、改名字 | 剪切粘贴 / 重命名 |
| `rm 文件` | 删除文件 | 删掉不要的 | `Shift + Delete`（**不进回收站**） |
| `rm -r 目录` | 删除整个目录 | 删文件夹 | 删文件夹（危险） |
| `rm -i` | 删除前一个一个问你 | 紧张时加一层保险 | 删除确认弹窗 |
| `ln -s 真身 链接名` | 建一个"快捷方式" | 在别处也能点到 | 右键 → 创建快捷方式 |
| `nano 文件` | 在终端里编辑文本文件 | 改配置、写笔记（`Ctrl+O` 保存、`Ctrl+X` 退出） | 记事本 |

### 3.3 找：文件 和 文件里的内容

**先分清这两个，这是重灾区**：Windows 里的 `find` 是**搜文件里的文字**；Linux 里的 `find` 是**按名字找文件**。**不是一回事。**

| 想干什么 | Windows | Linux |
| --- | --- | --- |
| 按名字找文件 | `dir /s`、资源管理器搜索 | `find 路径 -name "*.txt"` |
| 找文件里的文字 | `find "文本"` | `grep "文本" 文件` |
| 找命令装在哪 | `where 命令` | `which 命令` / `whereis 命令` |
| 快速全盘找文件名 | Everything | `locate 名字`（要先 `sudo updatedb`） |

常用组合：

```bash
find /home/wsqw -name "*.pdf"       # 在家目录里找所有 pdf
find . -type d -name "备份*"        # 只找目录（-type f 是只找文件）
grep -rn "关键词" /etc              # 在 /etc 里递归找内容，并显示行号
grep -i "error" app.log             # -i = 忽略大小写
```

### 3.4 权限与提权

| 命令 | 做什么 | 达到什么目的 | 相当于 Windows |
| --- | --- | --- | --- |
| `ls -l` | 看文件的那 9 个权限字母 | 搞清谁能读、谁能改 | 文件 → 属性 → 安全 |
| `chmod 755 文件` | 用数字改权限 | 让文件按需要开放 | 改文件的安全设置 |
| `chmod +x 脚本.sh` | 给文件加上"可执行" | 让脚本能跑起来 | 类似"允许像程序一样运行" |
| `sudo chown 用户:组 文件` | 改文件的属主和属组 | 换个"主人" | 改文件的所有者 |
| `sudo 命令` | 以 root 的身份跑这一条命令 | 完成系统级操作 | 用管理员身份运行 |
| `groups` / `id` | 看我在哪些组、我的编号 | 确认自己有没有 sudo 资格 | 看账户属于哪些用户组 |
| `su - 用户名` | 切换到另一个用户 | 换个身份干活（少用，退出敲 `exit`） | 切换用户 |

**数字权限速记**：`7` = rwx、`6` = rw-、`5` = r-x、`4` = r--。常见三档：

- `755` —— 目录、可执行文件
- `644` —— 普通文件（主人能改，其他人只读）
- `600` —— 私密文件（只有自己能碰，比如密钥）

（为什么 NTFS 盘上 `chmod` 不生效 → 见 [§2.4](#s2-4)）

### 3.5 管道与重定向（Linux 的灵魂）

**先澄清一个常见误解**：Windows 里**也有**管道 `|`，写法几乎一样。差别不是"有没有"，而是**主不主流** —— Unix 的思路是"每个小工具只干一件事，串起来干大活"，所以管道是主干道；Windows 一直是图形界面优先，命令行只是辅助。

| 写法 | 做什么 | 达到什么目的 | 例子 |
| --- | --- | --- | --- |
| `>` | 把输出**覆盖**写进文件 | 把结果存下来 | `ls -l > 清单.txt` |
| `>>` | 把输出**追加**到文件末尾 | 往文件里补内容，不覆盖旧的 | `echo "新行" >> 笔记.txt` |
| `<` | 从文件读入 | 把文件当输入喂给命令 |   |
| ```\|` | 把左边命令的输出，**交给**右边命令当输入 | 串起来干活 | `cat 日志 ``\| grep error` |
| `2>` | 把**错误**输出单独送走 | 正常输出和错误分开存 | `命令 2> 错误.log` |
| `2>&1` | 错误和正常输出合并送走 | 一份日志看全 | `命令 > 全部.log 2>&1` |
| ```\| tee 文件` | 既显示在屏幕上，又存进文件 | 边看边留档 | `命令 ``\| tee 结果.txt` |
| `> /dev/null` | 把输出丢进黑洞 | 不想要这些输出 | 相当于 DOS 的 `> nul` |

```bash
# 从几千行日志里捞出报错 —— 这就是"管道是主干道"的意思
cat app.log | grep -i error | tail -20
```

### 3.7 磁盘与挂载

| 做什么 | Windows | Linux |
| --- | --- | --- |
| 看有哪些盘、分区 | 磁盘管理 `diskmgmt.msc` | `lsblk` |
| 看分区详情 / UUID | 磁盘管理 | `blkid`（要 sudo） |
| 分区 | 磁盘管理（图形） | `gparted`（图形，推荐）/ `fdisk` |
| 挂载一块盘 | 插上就自动 | `sudo mount /dev/sdb1 /mnt/xx` |
| 卸载一块盘 | 弹出 U 盘 | `sudo umount /mnt/xx` |
| 看现在挂着哪些 |   | `findmnt` / `mount ``\| grep sda` |
| 开机自动挂载 | 盘符是先天就有的 | 改 `/etc/fstab`（⚠ 写错会开不了机） |

**规矩**：改 `fstab` 之前先备份（`cp /etc/fstab /etc/fstab.bak`），并且**先手动 **`mount`** 试通了，再写进去**。写错 `fstab` 会导致开机卡住，得进单用户模式去救。

（`fstab` 是"开机自动挂载的清单文件"，说明见 [§2.1](#s2-1)。表里的 **UUID** 是分区的唯一编号，长这样 `4AB004F1B004E4F3`；写进 `fstab` 时用它比用 `/dev/sda3` 稳，因为硬盘顺序可能变，编号不会变。）

## 五、外设与联网（第一天就要办的事）

> 这一节全是"不办成就没法用"的活儿。命令的注解跟 [§三](#s3) 一个格式：**命令 → 做什么 → 达到什么目的 → 相当于 Windows 的什么功能**。

### 5.1 中文输入法：怎么切、打不出中文怎么办

**先看会不会切**：默认按 `Ctrl + 空格` 在中英文之间切换（有的机器设成了 `Shift`）。

**图形上管输入法**：控制中心 → **键盘和语言** → 输入法。在这里添加、删除、调顺序。

你这台机器已经装了搜狗输入法（`sogou-ime-ng`）。哪天突然打不出中文了，按下面的顺序查：

| 命令 | 做什么 | 达到什么目的 | 相当于 Windows |
| --- | --- | --- | --- |
| `im-config` | 打开输入法框架的图形设置 | 选"用哪个输入法框架" | 控制面板里的"区域和语言" |
| `fcitx5 -d` | 手动把输入法后台服务拉起来 | 右下角图标不出现时救急 | 相当于手动启动一个后台程序 |
| `fcitx5-diagnose` | 打印一份体检报告 | 看是哪一环没配好 | 没有对应物 |
| `dpkg -l ``\| grep sogou` | 查搜狗输入法装没装、什么版本 | 确认它还在 | 控制面板 → 程序和功能 |

**三个最常见的毛病：**

1. **右下角没有输入法小图标** → 输入法后台没起来，`fcitx5 -d` 手动拉一下。
2. **能打出字母、打不出中文** → 输入法框架和当前程序没接上，**注销重登一次**通常就好。
3. **个别程序里切换失灵** → 图形界面程序大多正常；老程序的兼容问题，照 `fcitx5-diagnose` 的报告去查。

### 5.2 连网：WiFi 和网线

**图形上**：点任务栏右下角的**网络图标** → 列出的 WiFi 点一下、输密码就行。**插网线一般自动连**，不用管。

**命令行**（图形连不上时的救命家伙）：

| 命令 | 做什么 | 达到什么目的 | 相当于 Windows |
| --- | --- | --- | --- |
| `nmcli device wifi list` | 列出周围能搜到的 WiFi | 看有没有你要连的那个 | 点右下角网络图标弹出的 WiFi 列表 |
| `nmcli device wifi connect "WiFi名" password "密码"` | 直接连某个 WiFi | 图形连不上时硬连 | 点列表里那一项、输密码 |
| `nmcli connection show --active` | 看现在有没有连上网 | 确认当前状态 | 网络和共享中心里那个"已连接" |
| `ip a` | 看本机的 IP 地址 | 确认有没有拿到地址 | `ipconfig` |
| `ping -c 4 www.baidu.com` | 发 4 个包试通不通 | 分清是"没连上"还是"连上了出不了网" | `ping` |

**排查顺序**：`nmcli connection show --active`（连上没）→ `ip a`（拿到 IP 没）→ `ping`（能出网没）。

### 5.3 U 盘与移动硬盘

**U 盘**：插上 → 文件管理器**左侧栏**会冒出它的名字，点开就是内容。用完点它旁边的小三角"弹出"，再拔。

**移动硬盘（NTFS）**：一般也会自动出现。**但要是 Windows 那边是"关机/休眠"而不是真关机，或者开着快速启动，它就可能挂不上、或只能读不能写**（原因见 [§2.4](#s2-4)）。

| 命令 | 做什么 | 达到什么目的 | 相当于 Windows |
| --- | --- | --- | --- |
| `lsblk` | 列出所有盘和分区 | 确认系统到底认到这块盘没有 | 磁盘管理里看有没有冒出新磁盘 |
| `findmnt` | 看它挂在哪个文件夹下 | 找到它在树上的位置 | 看它分到了哪个盘符 |
| `sudo mount /dev/sdb1 /mnt/usb` | 手动把某块分区挂到 `/mnt/usb` | 自动挂载失败时手动来一下 | 相当于手动分配一个盘符 |
| `sudo umount /mnt/usb` | 卸载这个挂载点 | 拔之前先断开 | 右下角"安全删除硬件" |
| `udisksctl unmount -b /dev/sdb1` | 卸载（安全弹出） | 同上，另一种写法 | 同上 |
| `dmesg ``\| tail -30` | 看内核刚才报了什么 | 插上没反应时的第一诊断 | 事件查看器里的硬件日志 |

**红线**：**拔 U 盘前一定要先卸载**，否则可能丢数据（这点跟 Windows 一样）。

### 5.4 分辨率和字体

**分辨率 / 缩放**：控制中心 → **显示** → 选分辨率、调缩放。多显示器也在这里摆位置。

**装字体**（比如你想装的某个中文字体）：

| 命令 | 做什么 | 达到什么目的 | 相当于 Windows |
| --- | --- | --- | --- |
| `fc-list ``\| grep 关键词` | 列出已装字体里带这个关键词的 | 确认字体到底装上没有 | 控制面板 → 字体，看那一列 |
| `fc-cache -fv` | 刷新字体缓存 | 新拷进去的字体立刻被认出来 | 相当于让系统重新扫描一遍字体 |

**最省事的装法**：双击字体文件 → 弹出的"字体查看器"里点"安装"。手动装的话，把字体文件拷进 `~/.local/share/fonts/`，再跑一次 `fc-cache -fv`。

### 5.5 打印机和蓝牙

**打印机**：控制中心 → **打印**，能自动发现局域网里的网络打印机；插上 USB 打印机一般也会自己认出来。

**蓝牙**：控制中心 → **蓝牙**，打开开关，点"搜索设备"，配对。图形上跟 Windows 一样。

| 命令 | 做什么 | 达到什么目的 | 相当于 Windows |
| --- | --- | --- | --- |
| `lpstat -p` | 列出系统里的打印机 | 确认打印机配好了没 | "设备和打印机"列表 |
| `bluetoothctl` | 打开蓝牙命令行工具 | 图形配不上时硬配：进去后敲 `power on`、`scan on`、`pair 地址`、`connect 地址` | 蓝牙设置界面 |

### 5.6 访问 Windows 共享文件夹（SMB）

**先把一件事说清楚**：**你自己这台机器的双系统之间，不能这么互访** —— deepin 和 Windows 不会同时开机（理由见 `双系统工作空间的共享.md`）。两边要传数据，还是靠那块共用的 NTFS 盘（见 [§3.7](#s3-7)）。这里说的是**局域网里另一台 Windows 电脑**共享出来的文件夹。

**图形上**：文件管理器 → 地址栏输 `smb://对方IP/共享名` 回车 → 弹框输用户名密码。

| 命令 | 做什么 | 达到什么目的 | 相当于 Windows |
| --- | --- | --- | --- |
| `sudo apt install cifs-utils` | 装访问 SMB 共享要用的小工具 | 让系统有这个能力去挂共享目录 | 相当于装一个"网络邻居"的驱动 |
| `smbclient -L //192.168.1.5 -U 用户名` | 列出对方机器上有哪些共享 | 连之前先看看那边有什么 | 资源管理器里展开对方的共享列表 |
| `sudo mount -t cifs //192.168.1.5/共享名 /mnt/win -o username=用户名,uid=1000,gid=1000` | 把对方的共享挂到本机 | 像本地文件夹一样用 | 映射网络驱动器 |
| `sudo umount /mnt/win` | 断开这个共享 | 用完了卸掉 | 断开网络驱动器 |

**两个注意点：**

- 对方 Windows 那边必须**先把文件夹共享出来**、并允许 SMB；输的用户名密码是**对方机器上**的账户。
- `uid=1000,gid=1000` 是让挂上来的文件归你自己所有，不加会出现"看得见、动不了"。
