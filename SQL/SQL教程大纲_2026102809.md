## 一、先说这版改了什么

上一版我排的是「建表 → 增删改 → 查询」，廖雪峰的次序是：

**简介 → 概述 → 关系模型 → 在线SQL → 查询数据 → 修改数据 → MySQL → 事务 → 总结**

三处关键差异，他的排法更顺：

| 差异 | 我上一版 | 廖雪峰 | 为什么他对 |
|---|---|---|---|
| 查询与修改的先后 | 先增删改，后查询 | **先查询，后修改** | 新手第一步是"看数据"，不是"改数据"。查询占他全书 30%（23 页），修改只有 4 页 |
| 索引的位置 | 放在第四篇"数据库对象" | **放在关系模型里**（主键 → 外键 → 索引） | 索引和主键外键是同一层概念：都是"怎么组织一张表"，不是高级对象 |
| 动手环境 | 没有专门一章 | **"在线SQL"独立一节**，插在模型之后、查询之前 | 概念讲完先给个地方练手，再学查询，学一条验一条 |

另外他的篇幅比例也值得照搬：**查询 23 页 / MySQL 14 页 / 关系模型 10 页 / 事务 9 页 / 修改 4 页 / 简介 2 页**。
