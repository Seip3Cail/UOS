# 美国人打麻将，缺的不是麻将

四个人，一张方桌，洗牌的声音。最近有个说法，美国那边打麻将的人多起来了。

看到这儿，很多人的第一反应是文化输出。我不这么看。

我猜，火起来的不是麻将，是"见面"这件事。

一个人待着太容易了。手机上什么都有，饭能点，戏能看，话能对着屏幕说。日子过得下去，而且过得挺顺。可顺到最后，想找个人坐下来说会儿话，反倒要费点劲——不是没人，是没由头。"出来坐坐"这句话，越来越难说出口。

麻将恰好把这个由头补上了。

四个人，不多不少。两个人容易冷场，八个人自动分成几堆，四个刚好，谁都插得上话。规则能教，三圈下来就能上手，不用先学半年。最要紧的是时长——一局不是十分钟就散，是一坐一下午，一坐一晚上。它给的不是玩法，是一段时间。

这三条凑齐，换成别的也行。只不过麻将正好三条都占。

再往深一层，我觉得差别不在有没有地方聚，在见面要不要理由。

我们这边串门不用理由，推门就进，吃饭顺带就把话说了。社交是关系的副产品，不当正事办。

那边不一样。见人要先约，光说"来坐坐"说不出口，得有个名目——看球、吃饭、打牌。名目有了，人才坐得下来。

所以麻将给的是名目，不是场地。而且这个名目他们本来就有，叫 game night，打牌、玩桌游都算。麻将只是换了个玩法，塞进老框里。

顺带说一句我们这边。麻将退到棋牌室，不是因为别的好玩的多了，是凑不齐人。老院子拆了，亲戚住到城另一头，四个人凑不齐，只好去那种要付钱、要专门跑一趟的地方。它从日常变成了节目。

他们那边重新捡起来的，也是这个：一件能说出口的事。

牌还是那副牌。换的是打牌的人，和打牌的理由。

要坐下来的是人，不是牌。

你上一次专门为了见人出门，是什么时候？
