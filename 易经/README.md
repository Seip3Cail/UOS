# 易经（曾仕强《易经的智慧》）听讲笔记

一套听讲笔记工程：**讲稿是原料，笔记是成品，图片是插图，入口是索引。**

## 先打开哪一个

**`【目录】点着看.md`** —— 能读的都在那一页，想看哪一集点哪一集。
（点进去只看到黑字、不出树，按一次 Markmap 预览就有图。）

要盘家底、看进度、看哪集缺稿，翻 **`【总表】逐集对照.md`** —— 你有哪几集、每集讲什么、笔记做到哪、有没有讲稿，一张表看完。
集号就用你视频文件上的号（这套号＝官方书系号，1 阴阳之道 … 144 永怀希望），不必再换算别的编号。

不按集看、按事情找道理，翻 **`【索引】曾氏心法.md`**。

## 怎么读

**一篇一集，按集号往下走就行**，不用先读通《易经》。

- 每篇的结构是一样的：先看这一卦长什么样 → 曾教授从里面看出什么道理 → 他拿它解释哪件事 → 末尾一节「悟」。
- **末尾那个问题不用急着答。** 看着它往下翻下一篇，往往过几天自己会冒出来。
- 卦爻辞都给了原文加一句白话，不必回头查书。
- 想看看同一句话在多少卦里反复出现，翻 `【索引】曾氏心法.md`——**反复出现的，就是他真正要你记住的**。
- 看不进去的时候，就跳。这套东西不怕跳着看。

## 这套笔记的取向

**不是学《易经》，也不是讲经。** 是记录**曾仕强怎么从卦里悟出道理、再挪到做人做事上**（管理、用人、进退、危机、家庭）。
读书 → 做人 → 成长。所以每篇的重心是：

- 这一卦他看出了什么道理 → 他拿它解释什么现实 → 落到「人该怎么自处」。
- 卦爻辞给**原文 + 一句白话**，但**不做版本考证、不掉书袋**。

说白了：**要的是「曾氏怎么用」，不是「经文怎么解」。**

写的时候**不预设读者是谁**。每个人的处境不同，同一卦看出的东西也不同 —— 笔记只把材料摆好、把线头留出来，怎么悟是各人自己的事。

## 笔记体例（照这个写，别写成文章）

一篇笔记就是一棵树，不是一篇文章。规矩几条：

0. **文件名 = `集号_标题.md`**，集号就是视频上的编号（如 `018_师卦——师忧比乐.md`）；同一集有两篇的共用一个号（如 012 屯卦两篇）。

1. **只留骨架和原话**。能用曾教授自己的话当标题就用他的话，不替他改写、不替他升华。
2. **不写「综上所述」「本节讲了」** 这类话。没有过渡句，没有小结段。
3. **不堆表情、不用加粗铺满全篇**。层级靠 `#` 的深浅，不靠花样。
4. **卦爻辞给原文 + 一句白话**，不考证、不掉书袋。
5. 每篇末尾两个固定节：
   - `## 悟` —— 把这卦落回自处，**短、直**，不替读者升华；最后留一个问题，也**不给答案**（悟是各人自己的事）；
   - 一行来源声明。
6. 末尾**不写**「本文由 AI 生成」这类话，只写来源。
7. 稿源有出入的地方（网稿夹着别的东西、口语不通顺处），末尾声明里点一句，不混进正文。

## 用法

- **点着看**：VS Code 打开 `【目录】点着看.md`，按 `Ctrl+Shift+V` 出预览，点标题就到那一篇。
  注意要在 VS Code 里「打开文件夹」（把 `易经` 这个文件夹整个打开），只单独开一个 md 文件的话，点链接会被丢给浏览器，就报「无法访问此网站」了。
- **浏览器里点着看**：双击 `【网页版】笔记.html`，左边点标题、右边看内容，不需要 VS Code。
  排版按中文习惯：正文段首空两格、段与段之间留空行；标题一到六级，字号逐级递减，样式统一。
  配图一律缩成**同样大小**的小图（160×120，居中裁切），几张小图并排成格；**鼠标放上去看大图**（点一下或移开鼠标就收回）。
  网页用的是相对路径：**整个「易经」文件夹一起搬，到哪都能开；单把 html 拎出来，文字还在、图就没了。**
- **改名 / 重做网页**：在终端跑
  `python3 /mnt/winc/WorkBuddyData/wsqw_UOS/易经/工具_整理与网页.py`
  它把 `booknotes/` 的文件名统一成 `集号_标题.md`（和你视频上的编号一致），并重新生成网页版。可以反复跑，做完新笔记跑一遍就收进去。
- **看插图**：笔记里的图片路径是相对 `booknotes/` 的 `../images/xxx.png`，别单独移动 md 或 images。
- **要同步讲稿**：跑一次 `整理易经文件夹.sh`，工作区里新取到的讲稿会被抄一份进 `【素材】/`。
- **改内容**：转写稿不动；要改就改笔记。
